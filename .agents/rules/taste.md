# Taste & Aesthetic Standards

- **Vercel / Linear Aesthetic**: Strive for a minimalist, developer-centric, highly polished monochrome interface with sparse, purposeful accent colors.
- **Typography is King**: High contrast for primary text, low contrast for secondary (`text-muted`). Use precise tracking (letter-spacing) and leading (line-height). Headings should be tight.
- **Generous Whitespace**: Interfaces should breathe. Use ample, mathematically consistent padding and margins (multiples of 4/8 in Tailwind). 
- **Subtle Borders & Separators**: Use `border-border` (very light/dark gray) for division. Avoid solid black or highly saturated borders.
- **Elevations & Depth**: Use subtle multi-layered drop shadows (`shadow-sm`, `shadow-neo`) for floating elements. Combine with `backdrop-blur-md` and `bg-surface/80` for glassmorphism where appropriate.
- **No Default Colors**: Never use pure red (`#FF0000`), pure blue, etc. Always use tailored, slightly desaturated, harmonic shades.
- **Empty States**: Empty states should be beautifully designed, often featuring a subtle icon and muted text, guiding the user on what to do next.
- **Zero Visual Noise**: Remove anything that does not serve a direct purpose. Less is more.
